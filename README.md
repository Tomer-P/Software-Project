# Software Project — Clustering Algorithms in C and Python

A collection of assignments from the **Software Project** course at **Tel Aviv University**, exploring clustering algorithms, numerical programming in **C**, and integration between **Python and C**.

## Projects

| Part | Topic | Highlights |
| --- | --- | --- |
| [HW1](HW1/) | K-means | Implementations of K-means in C and Python |
| [HW2](HW2/) | K-means++ | Probabilistic centroid initialization in Python and a CPython C extension for the clustering algorithm |
| [Final Project](Final-Project/) | SymNMF | Similarity and degree matrices, normalized similarity, iterative symmetric non-negative matrix factorization, and comparison with K-means |

## Technologies and concepts

**C · Python · NumPy · CPython C API · Clustering · Matrix operations · Memory management · Algorithm implementation**

Each project directory contains its own source files and instructions for building and running the programs.
